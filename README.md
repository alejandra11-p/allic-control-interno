# ALLIC · Evaluación del Control Interno

Herramienta digital para la evaluación del control interno y la identificación de riesgos a partir de los estados financieros, con base en el Marco Integrado de Control Interno COSO 2013 y las Normas Internacionales de Auditoría.

**Usar en línea:** https://alejandra11-p.github.io/allic-control-interno/

- Funciona en el navegador (computadora o celular), sin instalar nada.
- El acceso está protegido con PIN.
- Los encargos se guardan solo en el navegador de cada persona; no se envían a internet. Para pasarlos a otro equipo, use «Respaldar todo» e «Importar respaldo».

Proyecto de grado.
